## Built, tested, NOT deployed

**Duel Edge Function.** `supabase/functions/duel/bundle.ts` is a deploy-time artifact and is stale
against `HEAD` (it still embeds bot 5 for level 13, among other drift). It must be rebuilt with
`npm run server:build-edge` and redeployed before any server-side change ships. Nothing in the live
site depends on it today.

**No migrations were applied.** The map expansion needs none: the world geometry is code, and
`world_claims` is keyed by cell id text, so v2 cells simply become claimable.

## How to roll back

A bad publish is reverted forward, never force-pushed:

```sh
git -C <worktree> fetch https://github.com/severgrow/severgrow-01.git futa0.5-online
git -C <worktree> revert --no-edit <bad-commit>
git -C <worktree> push https://github.com/severgrow/severgrow-01.git HEAD:futa0.5-online
```

CI gates the deploy, so a revert re-runs the full suite before the site changes.

## Confirmed changes

1. **Installed iPhone surface and layout disagreed.** Recent CSS floors its height at `100lvh`, but
   JS previously calculated a different height from `innerHeight`/`screen.height`. A restored PWA
   could paint one height while fitting its board/cockpit to another. One measured large-viewport
   source now supplies both, including landscape. Existing screen-based fallback and safe-area
   reservation remain. Safari tabs still use their visible viewport. No extra frame loop.
2. **Direct accounts.** Supabase email one-time codes now work inside the game; Google remains an
   option. Existing players, guest upgrades, matches and ownership use the same canonical link.
   Old servers and unconfigured mail keep the new option hidden. See [EMAIL-ACCOUNTS.md](EMAIL-ACCOUNTS.md).
3. **Code verification / exchange retry.** A one-use code is not resubmitted after a lost game-server
   response. Its verified session remains in memory for retry, and the canonical subject lookup
   prevents duplicate accounts. Local guest upgrades still get the required nickname prompt after
   such a retry. Codes and Supabase tokens are never persisted.
4. **Account requests could spin indefinitely.** Auth settings, game exchanges, match-existence
   reads and OAuth token exchanges now have a deadline through body parsing. Server-to-Supabase
   verification/deletion also has a deadline. Malformed responses cannot mark a sign-in successful.
5. **Deletion could falsely succeed / remove recovery too early.** Supabase deletion is confirmed
   before the recovery link is removed. A failed deletion now reports failure and preserves the
   account and its link; the existing sign-out-other-devices behavior remains after success.
6. **Method-specific identity/UI assumptions.** Device account records, the first-frame menu key,
   Settings, profile and privacy copy now support email and Google. All new labels use the existing
   strings module. The form uses the existing dark glass, sheet motion, focus trap, visible focus,
   44px controls, 16px input floor and keyboard viewport sizing. Secondary actions are quiet links.

regression, then exposed an intermittent repeated-tap assertion at 1440px. Diagnostic runs compared

removing the failing assertion. Final rerun passed: 883 cockpit checks, 3,597 sorting/pile checks, the score-restart regression,

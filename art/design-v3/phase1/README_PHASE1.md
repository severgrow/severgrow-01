# SEVEROR V3 — Phase 1 delivery

This package stops at Phase 1 for visual approval.

It contains real separate assets used to assemble the style frames:
- seamless empty/gold/forest/lush/volcano/hot terrain
- exact V3 masks copied unchanged from the starter
- one blocked-rock cluster
- forest top-down home layers
- volcano top-down home layers
- forest/lava network strips
- forest/volcano scar decals
- six pointy/flat style frames at 40/80/150 px
- grayscale equivalents
- 3×3 repeat proofs
- numeric seam report

The composite style frames are review files only and must never be used as runtime art.

No Phase-2 full prop library has been produced yet.

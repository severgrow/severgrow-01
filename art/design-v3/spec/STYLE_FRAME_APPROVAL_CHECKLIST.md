# Phase-1 style-frame review checklist

Approve only if all are true:

## System
- [ ] Adjacent owned tiles read as one continuous surface, not individual pictures.
- [ ] Pointy and flat both look authored, not rotated hacks.
- [ ] Board rotation/light logic can remain screen-upright.
- [ ] Network is unmistakably the primary structural graphic.

## Readability
- [ ] 40 px version is clean and not mushy.
- [ ] 64/80 px version has no one-pixel noise.
- [ ] 150 px version gains richness without revealing cheap repetition.
- [ ] Number zones are calm.
- [ ] Gold badge zone is calm.
- [ ] Forest/volcano are distinguishable in grayscale.

## Hierarchy
- [ ] Network > homes > owned ground > props > gold > rock > empty.
- [ ] Rock is blocked and readable but visually quiet.
- [ ] Homes are special without becoming isometric stickers.

## Style
- [ ] Strict top-down.
- [ ] One coherent light direction.
- [ ] Large painted shapes.
- [ ] No photo texture.
- [ ] No AI micro-noise.
- [ ] No obvious contact-sheet/crop artefacts.
- [ ] No hex outline baked into art.

## Technical
- [ ] Phase-1 textures tile seamlessly.
- [ ] Repeat proofs show no edge seam.
- [ ] Style frame is assembled from separate real assets.
- [ ] Style frame is NOT itself intended as a production atlas.

If any critical item fails, revise Phase 1 before producing the full pack.
